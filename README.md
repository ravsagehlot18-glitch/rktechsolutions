## RK TECH AI business agent (starter)

Open `agent.html` in a browser or deploy it with GitHub Pages. It includes:
- Bilingual (Hindi + English) customer FAQ assistant
- Repair enquiry capture and CSV export
- Local sales/expense tracker
- Marketing and repair/inventory operating checklists

### Local development
Requires Node.js 20 or later for the tests:
```bash
npm test
```

### Important limitations
This is a browser-based starter, not yet a connected generative-AI agent. Lead and finance entries are stored only in the current browser's local storage; they are not synchronized or backed up. No WhatsApp, Google Business Profile, BUSY, GST, inventory database, payment or advertising account is connected. Do not enter sensitive customer, payment, password or identity information. Confirm repair diagnoses, prices, warranties and stock manually before communicating them to customers.

### Next integrations
A secure server-side AI provider, authenticated database, WhatsApp Business Platform, BUSY export/import workflow, and authorized Google/Ads integrations must be configured separately. API keys must never be placed in browser JavaScript or committed to this public repository.
